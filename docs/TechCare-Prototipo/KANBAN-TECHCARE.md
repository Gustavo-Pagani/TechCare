## Como explicar o Kanban na apresentação

O quadro Kanban foi usado para organizar visualmente o avanço do projeto TechCare. As tarefas foram divididas em três estados: **A Fazer**, **Em Andamento** e **Concluído**. Isso permite acompanhar o que ainda precisa ser desenvolvido, o que está sendo trabalhado pelo grupo e o que já foi entregue no protótipo inicial.

Essa organização ajuda o grupo a manter o foco no MVP do semestre, priorizando primeiro as funcionalidades essenciais: protótipo web, mapa territorial, indicadores principais, planejamento do banco de dados, API e algoritmo de cálculo.
